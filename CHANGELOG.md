# Change Log

All notable changes to the "ouaf-config-manager" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [Unreleased]

- Added Data Area browsing and View-only XML XPath inspection through `CmScriptAsTextViewer` option `D`.
- Added separate Steps (`S`) and Schema (`X`) retrieval and checkout behavior.
- Added OUAF deployment prerequisites and documented support testing against Oracle Customer Care and Billing `v2.4.0.3` and Oracle Application Framework `v4.2.0.3`.
- Added selectable XML leaf elements rendered as self-closing tags in the XML View.
- Renamed the explorer category to Script and hid unsupported component categories.
- Added multi-select checkout and checkout of all filtered Scripts.
- Added Steps and Schema comparison, Schema formatting, and replacing Steps from another environment.
- Added local status indicators, environment connect/disconnect controls, and Collapse All.
- Added local Check-in cleanup with timestamped backups.
- Added local-file-first opening for Steps and Schema.
